# Radar de Alertas — Código reunido

`backend/`: API e cron AWS Lambda / Supabase PostgreSQL / Prisma.
`mobile/`: React Native / Expo, login, cadastro, recuperação de senha, monitoramentos, notificações.
`docs/`: guia funcional, roteiro de testes e prévia HTML.
`.github/workflows/`: validação e deploy do backend.

**Leia `RELEASE_STATUS.md` antes de publicar.** O projeto **não está pronto para produção**: há bloqueios técnicos e funcionalidades ainda não implementadas. Não configure pagamentos reais nem usuários finais antes da homologação.
